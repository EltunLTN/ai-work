# Premium Kairo interface

Scope follows the direct request for the home page, navigation, floating assistant and university goals, plus the supplied eight-card Tools brief. Existing account boundaries, RPC ownership and AI budgets are retained; no generated visual is presented as a student result.

- Home uses the existing rabbit portrait, a 48/52 composition, short copy, direct trial/discovery actions, subtle ambient lighting, bounded pointer parallax, scroll-linked movement and an explicit animation pause button. Its watch links to Focus. The ad hoc announcement strip is removed from the home composition.
- The four-step journey explains diagnostic trial, personal plan, deeper learning and practice. It remains readable without motion and has direct links.
- Eight Tools cards share a consistent layout and individual original SVG visuals: answer sheet, teaching flow, target meter, focus dial, duel, bracket, real sampled quadratic curve and mistake correction. Short hover/focus sequences rest afterward. Illustrations are decorative; status text is sourced from existing home/focus/mistakes RPCs or honest empty states. Focus countdown renders only for an actual session. Existing card routes remain intact.
- Goals add a personal primary-goal overview, real compatible-score progress, an 18-at-a-time program card catalogue, search, university/language/group filters, sorting and up to three side-by-side comparisons. Source links remain removed, while preliminary/unverified status remains explicit. Existing goal save/primary/archive actions remain unchanged. Saved goal values prefill when selecting the same program again.
- Responsive grids, keyboard focus, native dialog semantics and system/product reduced-motion support apply throughout. No new animation, WebGL, media or chart dependencies were added.

Validation: existing 75 tests, TypeScript, ESLint, Linux preview build, desktop/mobile visual checks, card navigation/focus and real-account goal comparison checks are release gates.
