# Visible rabbit v2

The rabbit now uses an original ImageGen render with real transparency, saved as `public/kairo/rabbit-guide-v2.png` (1086 × 1448). Generated with the built-in image tool, not the website's OpenAI API key. The original generated file was preserved.

The home-page rabbit stays large and visible. The companion and entrance use the same asset with restrained CSS motion. Removed the running WebGL renderer, the automatic hero-to-dock timer and the global class that hid the original rabbit. The existing vector character is a fallback only if the image cannot load. Reduced-motion support remains enabled. An old hidden preference is reset once for this visual upgrade; the user's Hide button remains available afterward.
